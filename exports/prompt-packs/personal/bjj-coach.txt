# BJJ Training Reflection Pack

Version: 0.7.0
Tags: pack, bjj, jiu-jitsu, training, reflection, improvement

Use this pack after training sessions to extract learning, identify patterns,
and set intentions for the next session.

## Recommended Modes

- Analyze
- Coach
- Plan

## Training Session Reflection

```text
Use Atlas One Analyze Mode.

Help me reflect on today's BJJ training session.

What happened:
[describe sparring rounds, drilling, what you worked on]

Tell me:
- What worked and why it might have worked
- What failed and what the failure reveals
- A pattern across multiple sessions if I describe more than one
- One technical area to focus on next session
- One mental or positional habit to notice
```

## Game Plan Development

```text
Use Atlas One Architect Mode.

Help me build a BJJ game plan.

My level: [beginner / intermediate / advanced]
My physical attributes: [size, speed, flexibility, strength]
My current go-to positions: [e.g. guard, half guard, top pressure]
Gaps I know I have: [e.g. weak back defense, no leg lock entries]

Return:
1. A clear game plan from standing to finish
2. Primary positions and transitions
3. Secondary options when primary fails
4. Positions to avoid until stronger
5. Two techniques to drill this week
```

## Pre-Competition Focus

```text
Use Atlas One Plan Mode.

I have a competition coming up. Help me prepare mentally and tactically.

Competition type: [gi / no-gi / submission only / points]
My division: [weight / belt]
Time until competition: [days / weeks]
My current concerns: [e.g. nerves, specific positions, stamina]

Return:
1. What to prioritize in remaining training
2. What to stop drilling to avoid overcomplicating my game
3. Mental preparation strategy
4. Day-of routine
5. What "winning" looks like beyond the scoreboard
```

## Technique Breakdown Request

```text
Use Atlas One Teach Mode.

Break down [technique name] for me.

Tell me:
- What position it starts from
- The mechanical key that makes it work
- Common setups and entries
- What the opponent feels and will try to counter
- How to finish if the first attempt fails
- A drilling drill to build the movement pattern
```

## Example Usage

```text
Goal:
Reflect on a rough sparring session where I kept getting my guard passed.

Mode:
Analyze

Output:
What the pattern reveals, one positional adjustment, one drilling focus.
```
