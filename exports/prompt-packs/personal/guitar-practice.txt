# Guitar Practice Prompt Pack

Version: 0.7.0
Tags: pack, guitar, practice, music, learning, technique

Use this pack to structure practice sessions, diagnose stuck points,
and plan deliberate improvement across technique, ear, and repertoire.

## Recommended Modes

- Plan
- Coach
- Analyze

## Practice Session Planner

```text
Use Atlas One Plan Mode.

Help me plan a focused guitar practice session.

Available time: [minutes]
Current focus area: [e.g. technique, a specific song, ear training, theory]
Where I am stuck: [describe the specific issue]
Long-term goal: [e.g. play this song cleanly, improve improvisation, faster runs]

Return:
1. Session structure with time allocation
2. Warm-up routine
3. Main focus exercise with clear instructions
4. How to know when the session was productive
5. What to log for next time
```

## Stuck Point Diagnosis

```text
Use Atlas One Analyze Mode.

I am stuck on [specific technique or passage].

What I'm experiencing: [describe what happens, where it breaks down]
How long I've been working on it: [time]
What I've already tried: [approaches taken]

Tell me:
- What the underlying issue likely is
- Whether I am practicing the right thing or practicing the problem
- A different approach or drill to try
- How to practice this more slowly or differently to unlock it
- What progress should feel like
```

## Repertoire Development

```text
Use Atlas One Plan Mode.

Help me build a practice repertoire.

My current level: [beginner / intermediate / advanced]
Style I'm focused on: [classical / fingerpicking / rock / jazz / other]
Songs I can already play: [list]
Songs I want to learn: [list]

Return:
1. A 3-month learning path ordered by difficulty and skill transfer
2. What each song teaches technically
3. Which songs to tackle in parallel vs in sequence
4. How much time per song per week
```

## Ear Training Integration

```text
Use Atlas One Teach Mode.

Teach me how to develop my ear as a guitarist.

My current level: [can / cannot] recognize intervals by ear
My practice context: [solo / with others / learning songs by ear]

Cover:
- Where to start (what to train first)
- Daily drill under 10 minutes
- How to apply ear training to actual songs
- When to use a reference note vs train relative pitch
- How to know if it is working
```

## Example Usage

```text
Goal:
I have 30 minutes. I want to make real progress on a fingerpicking pattern
that keeps falling apart at tempo.

Mode:
Plan

Output:
Session structure, focus exercise, how to measure progress.
```
