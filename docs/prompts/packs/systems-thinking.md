# Systems Thinking Prompt Pack

Version: 0.3.0
Tags: pack, systems, feedback-loops, architecture, leverage

Use this pack when a problem has feedback loops, delays, incentives or hidden
constraints.

## When to Use

* When a fix keeps failing and the real cause is structural, not local
* When behavior involves feedback loops, delays or incentives
* When you need the highest-leverage intervention, not just the obvious one

## Recommended Modes

* Analyze
* Architect
* Decide

## Starter Prompt

```text
Use Atlas One Analyze Mode with a systems-thinking lens.

Map:
- visible symptoms
- underlying structure
- reinforcing loops
- balancing loops
- delays
- constraints
- leverage points

End with the smallest high-leverage intervention.
```

## Expected Output

* A separation of visible symptoms from underlying structure
* The reinforcing and balancing loops, plus delays and constraints
* Named leverage points, ordered by leverage
* One smallest high-leverage intervention to try first

## Constraints

* Describe structure over blame — no single-cause "someone messed up"
* Do not invent dynamics the inputs don't support; flag assumptions
* Analysis only — this pack maps the system, it does not enact changes

## Example Usage

```text
Goal:
Understand why review turnaround keeps slipping despite adding reviewers.

Mode:
Analyze

Output:
Symptoms vs structure, the loops and delays involved, leverage points, and the
smallest high-leverage intervention.
```
