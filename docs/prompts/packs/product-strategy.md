# Product Strategy Prompt Pack

Version: 0.3.0
Tags: pack, product, strategy, roadmap, decisions

Use this pack to shape positioning, offers, roadmaps and product direction.

## When to Use

* When choosing between competing product directions or offers
* When positioning is unclear and you need to sharpen it
* When a roadmap needs a rationale, not just a list of features

## Recommended Modes

* Research
* Decide
* Plan

## Starter Prompt

```text
Use Atlas One Decide Mode.

Help choose the strongest product direction.

Compare:
- audience
- problem urgency
- differentiation
- proof
- implementation cost
- risk

Recommend one direction and explain the trade-offs.
```

## Expected Output

* A comparison across the stated dimensions, not a vague opinion
* One recommended direction, clearly named
* The trade-offs accepted by choosing it
* The condition under which the recommendation would change

## Constraints

* Ground claims in the inputs given; do not invent market data
* Separate fact, interpretation and recommendation
* Advisory only — this pack shapes thinking, it does not commit a roadmap

## Example Usage

```text
Goal:
Decide whether Atlas One should position as a prompt library or a local
workflow studio for the next release.

Mode:
Decide

Output:
Dimension-by-dimension comparison, one recommended direction, trade-offs, and
the signal that would change the call.
```
