# Legacy prototype source

Retired prototype files kept for reference only. Nothing here is built,
served, or referenced by the live app (`index.html`, `docs/index.html`) or the
Java backend.

The live prompt runtime is `atlas-final-prompt-v3-generic.js` (root and
`docs/`); these `v2` and `atlas-ui-patch` files were superseded by it.

* `atlas-final-prompt-v2.js`, `atlas-final-prompt-v2-generic.js` — earlier
  prompt-generation iterations, replaced by `v3`.
* `atlas-ui-patch.js`, `atlas-ui-patch.css` — one-off UI patch merged into the
  main UI.
* `atlas-ui-main-section.html` — extracted markup fragment, no longer included.

Safe to delete outright if the reference value ever lapses; full history
remains in git.
