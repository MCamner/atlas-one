# Skills

Atlas One ships lightweight skills for maintaining prompt modes, prompt packs
and reusable reasoning templates.

## Built-in skills

### prompt-pack-maintainer

Maintain Atlas One prompt modes, prompt packs, mq ecosystem boundary prompts,
prompt metadata and prompt-library docs.

```text
skills/prompt-pack-maintainer/SKILL.md
```

Use this when changing `docs/prompts/`, `docs/PROMPT_LIBRARY.md`, `docs/MODES.md`,
`docs/ROUTING.md`, `docs/EXAMPLES.md`, `docs/prompts.json` or prompt-pack
exports.
